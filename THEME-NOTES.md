# Theme source

This global site was restyled from the supplied Godavari Basket India codebase.

Carried forward intentionally:
- Deep forest green: `#062b18`
- Antique gold: `#c9a24a`
- Warm paper / cream surfaces
- Cormorant Garamond display typography + Manrope UI typography
- Godavari landscape / regional food photography
- Gold dividers, subtle borders and restrained editorial copy
- "From Godavari, With Love." brand language

Global changes:
- Softer 20–34 px radii instead of sharp blocks
- More whitespace and fewer simultaneous text elements
- Scroll reveal, hover lift, image zoom, progress and floating motion
- Persistent 5 kg+ box builder
- Google Sheet catalog sync
